# Hotel Booking Analysis Dashboard

## Overview
This project is an interactive Excel dashboard built to analyze hotel booking data and provide insights into booking trends, revenue, customer behavior, and operational performance. The dashboard enables users to filter data dynamically using slicers for deeper analysis.

## Objectives
- Analyze hotel booking performance.
- Monitor revenue and cancellation rates.
- Understand customer segments and booking behavior.
- Identify seasonal booking trends.
- Support data-driven decision making.

## Key Metrics
- Total Bookings
- Cancellation Rate
- Average Daily Rate (ADR)
- Total Revenue
- Average Stay (Nights)

## Dashboard Features
- Revenue by Hotel
- Revenue by Season
- Guest Type Distribution
- Payment Risk Analysis
- Revenue by Customer Type
- Lead Time Category Analysis

## Interactive Filters
- Hotel
- Year
- Marital Status
- Customer Type

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- KPI Cards
